# Etch-a-Sketch

Projeto do currículo Foundations do The Odin Project. Uma versão simples
de um "quadro mágico" no navegador, onde o mouse pinta uma grade de
quadrados conforme passa por cima.

## O que foi praticado

- Criação de elementos DOM via JavaScript (`createElement`, `appendChild`)
- Organização de grade com Flexbox (`display: flex`, `flex-wrap: wrap`)
- Eventos de mouse (`mouseover`) e `e.target` para identificar o elemento
  exato sob o cursor
- Remoção e recriação de conteúdo (`innerHTML = ''`) para redesenhar a
  grade com um novo tamanho

## Como rodar

Abra o arquivo `index.html` em qualquer navegador.
